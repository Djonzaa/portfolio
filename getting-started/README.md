# Getting Started

This section contains general information for installing and configuring Djonza Development resources.

## Recommended Setup

Djonza Development resources are designed with modern FiveM server environments in mind.

Before installing a resource, always check its individual **Requirements** page.

## Installation Flow

1. Check requirements.
2. Install dependencies.
3. Import required SQL.
4. Configure the resource.
5. Add the resource to `server.cfg`.
6. Restart the server.
7. Check the server console for errors.
