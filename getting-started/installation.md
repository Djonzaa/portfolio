# Installation

## Standard Installation

### Step 1 — Download

Obtain the resource from the official Djonza Development release source.

### Step 2 — Extract

Place the resource inside your server's resources directory.

### Step 3 — Dependencies

Install every dependency listed in the resource documentation.

### Step 4 — Database

If the resource includes SQL, import it into your server database.

### Step 5 — Configuration

Open the resource configuration and adjust the available options.

### Step 6 — Start

Add the resource to your `server.cfg`:

```cfg
ensure resource_name
```

### Step 7 — Restart

Restart the server and verify the console for errors.
