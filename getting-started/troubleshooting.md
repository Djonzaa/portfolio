# Troubleshooting

## Resource does not start

Check:

- Resource folder name
- `fxmanifest.lua`
- `server.cfg`
- Dependencies
- Console errors

## Database errors

Check:

- Database connection
- SQL import
- Table names
- Database permissions

## NUI does not open

Check:

- Client-side errors
- NUI files
- Resource manifest
- Browser console errors

## Callback or export errors

Make sure the required dependency is running before the Djonza Development resource.

If the issue continues, contact Djonza Development support with the full console error.
