# Paid Releases

Welcome to the **Djonza Development Paid Releases**.

This section contains documentation for commercial Djonza Development resources.

Each product has its own documentation covering installation, configuration, dependencies, permissions, integrations, commands, exports and troubleshooting.

### Adding a new paid resource

1. Duplicate `TEMPLATE.md`.
2. Rename it to the resource name.
3. Add the resource to this page.
4. Add the page to `SUMMARY.md`.

Example:

- [d-MDT](d-mdt/README.md)
- [d-Fines](d-fines/README.md)
